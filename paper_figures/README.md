# Exact paper figures

This directory is deliberately separate from `experiments/`.

## Rule

The scripts in `paper_figures/scripts/` must reproduce **exactly the figures included in the final TECNIACÚSTICA 2026 paper**:

- same panels;
- same panel order;
- same data;
- same axis limits;
- same labels and annotations;
- same colors and line styles;
- same legends;
- same numerical values;
- same export dimensions / aspect ratio where practical.

They should consume the validated outputs generated by `experiments/scripts/`.
They must not silently rerun a modified experiment.

## Layout

```text
paper_figures/
├── scripts/
│   ├── figure_1_framework.py
│   ├── figure_2_measurement_geometry.py
│   ├── figure_3_transport_multibasin.py
│   └── reproduce_all_figures.py
├── reference/        # canonical exports from the submitted/final paper
└── generated/        # regenerated exports for comparison
```

`reference/` should contain the exact canonical PDF/SVG/PNG assets used in the paper once those source assets are available.

A release should only be tagged after regenerated figures have been checked against the canonical paper assets.
